# Data

This directory contains datasets used for the healthcare LLM consistency evaluation.

## Structure

- `raw/` - Original datasets and collected healthcare questions before processing
- `processed/` - Cleaned and structured data used by the evaluation pipeline

Processed data may include:
- Original healthcare questions
- Healthcare domain labels
- False-presupposition labels
- Clinician-escalation labels
- Meaning-preserving paraphrases

Large or externally sourced datasets may not be committed directly to the repository.
